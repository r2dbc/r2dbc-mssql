R2DBC driver implementation for Microsoft SQL Server using the TDS protocol.

Getting Started

Obtain a {@code ConnectionFactory} through URL connection factory discovery:

ConnectionFactory connectionFactory = ConnectionFactories.get("r2dbc:mssql://<host>:1433/<database>");

Publisher<? extends Connection> connectionPublisher = connectionFactory.create();

through programmatic discovery with {@code ConnectionFactoryOptions}:

ConnectionFactoryOptions options = ConnectionFactoryOptions.builder()
    .option(ConnectionFactoryOptions.DRIVER, "sqlserver")
    .option(ConnectionFactoryOptions.HOST, "…")
    .option(ConnectionFactoryOptions.USER, "…")
    .option(ConnectionFactoryOptions.PASSWORD, "…")
    .option(ConnectionFactoryOptions.DATABASE, "…")
    .build();

ConnectionFactory connectionFactory = ConnectionFactories.get(options);

or through {@link io.r2dbc.mssql.MssqlConnectionConfiguration} for programmatic configuration:

MssqlConnectionConfiguration configuration = MssqlConnectionConfiguration.builder()
    .host("…")
    .username("…")
    .password("…")
    .database("…")
    .build();

MssqlConnectionFactory connectionFactory = new MssqlConnectionFactory(configuration);

Mono<MssqlConnection> connectionMono = connectionFactory.create();

See {@link io.r2dbc.mssql.MssqlConnection} for statement creation and transaction control, {@link io.r2dbc.mssql.MssqlResult} for consuming rows and update counts, and {@link io.r2dbc.mssql.MssqlException} for server error reporting.
